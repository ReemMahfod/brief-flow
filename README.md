# BriefFlow

Meeting management for teams — agendas, decisions, tasks, and follow-up.

## Features

- Create and manage meetings
- Capture decisions
- Assign and track tasks
- Dashboard overview and simple reports

## Tech stack

- React (Create React App)
- React Router
- Context API
- Tailwind CSS
- localStorage for persistence

## Run

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000)

## Pages

| Page | Purpose |
|------|---------|
| Login | Sign in |
| Dashboard | Today’s meetings, overdue tasks, progress |
| Meetings | List and filters |
| Meeting details | Agenda, attendees, notes, decisions, tasks |
| Create / Edit | Create and edit meetings |
| Tasks | Task list and status updates |
| Decisions | Decision log |
| Reports | Simple stats |

## Notes

Any username and password can be used for the demo login.
